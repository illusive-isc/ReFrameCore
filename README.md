# ReFrameCore

ReFrame の共通部分です。**アバター用のパッケージ (ReFrame for kaguya など) を入れると、依存として一緒に入ります。** 単体で使うものではありません。

ReFrame は、アバターに入っている「使わない衣装・ギミック」をチェックするだけで、アップロード時に自動で取り除く仕組みです。

- 元のアセット (メニュー・アニメーター・パラメーター) は書き換えません。取り除くのはビルドの中だけで、プロジェクトのファイルはそのまま残ります。
- パラメーターの空きが増えるので、他のギミックを足す余裕ができます。
- 「Quest 簡易対応版」を作ると、同じアバターを Quest 向けにも出せます。

## 動作環境

- Unity 2022.3 / VRChat SDK 3.7 以降
- NDMF 1.6 以降、Modular Avatar 1.13 以降
- Avatar Optimizer 1.8 以降、lilToon 1.7 以降

いずれも VCC (または ALCOM) で自動的に入ります。

## 導入

1. VCC に ReFrame のリポジトリを追加します: <https://reframe.illusive-isc.jp/>
2. 使うアバターのパッケージ (例: `ReFrame for kaguya`) をプロジェクトに追加します。ReFrameCore は一緒に入ります。

## 使い方

1. Hierarchy でアバターを右クリック → **ReFrame → このアバターに ReFrame を追加**
2. 追加された `ReFrame` オブジェクトの Inspector で、**使わない衣装・ギミックにチェック**を入れます。
   - チェックした項目が Scene と Hierarchy から消えて見えるので、消し過ぎに気づけます (「プレビューに反映」で切り替え)。
   - 上部にパラメーターの空き容量が出ます。
3. いつもどおりアップロードします。チェックした項目だけがビルドから取り除かれます。

チェックを外せば元に戻ります。プロジェクトのファイルは一切変わっていません。

## Quest 簡易対応版

Inspector 上部の **「Quest 簡易対応版を作成」** を押すと、その時点の設定を引き継いだ Quest 用の設定が同じオブジェクトに増えます。

- Quest 用は、使わないものに加えて **Quest で動かないコンポーネント・揺れ物・マテリアル** をここで減らします。マテリアルは Toon Lit へ焼き込んで差し替えます (元のマテリアルは変わりません)。
- Quest 側の Inspector には、Quest でアップロードが止まる項目と、超えているが通る項目が分けて出ます。
- ビルドターゲットが Android のときに Quest 用の設定が使われます。PC のときは PC 用の設定のままです。

## 注意

- メッシュ・シェイプキー・マテリアルの削減は担当していません。Avatar Optimizer の Trace and Optimize と併用してください (無いと Inspector に案内が出ます)。
- 取り除いた項目のメニューやパラメーターを他のギミックが参照していると、そのギミックは動かなくなります。チェックしてからプレビューで確かめてください。

## 更新

新しい版が出ると Inspector の上部に通知が出ます。VCC から更新してください。変更点は [CHANGELOG](CHANGELOG.md) にあります。
